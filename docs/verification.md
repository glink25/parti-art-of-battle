# 本轮验证结果

环境：Apple M3 / darwin / Node v22.19.0。版本：0.2.0，规则：`twins-original-02`，模拟版本：2，内容哈希：`adb2745b`。

- TypeScript strict、模块边界、内容表校验通过。
- 34 项纯逻辑测试通过；覆盖确定性动作阶段、控制打断、释放后弹道、范围落点命中、回放动作快照、延时自爆，以及原有换位、版本冲突和共享布阵判定。
- 生产构建、完整 ZIP、文件入口与权威 Worker 打包契约检查通过。
- 生产房间入口与单文件权威 Worker 契约检查通过；本轮未修改或启动 Parti 主仓库，未重复运行此前验证过的外部 Harness 输出模式。
- Vite 开发服务器启动成功，页面及开发 Worker 模块 HTTP 返回成功；未进行浏览器操作或画面验收。
- 5 局完整规则模拟完成，seed 1000–1004，共 7485 条合法/拒绝决策指令；逐条检查卡池、位置、归属、人口等不变量。
- 局长 26–33 回合，最大权威快照 113349 字节，低于 200 KB 工程目标。

| Node CPU 场景   | 整轮 P95 | 单切片 P95 |
| --------------- | -------- | ---------- |
| four-32         | 14.13 ms | 0.29 ms    |
| eight-64-stress | 74.09 ms | 1.00 ms    |

上述是本机 CPU 基准，不含浏览器计时器、网络传输、渲染，也不能当作移动设备验收。64 实体压力场景高于正式游戏的 32 初始单位上限。

批量模拟中两个人类席位也由相同策略代为操作，仅用于验证完整规则循环。它不是人类玩法胜率测试。第一版阵容强度尚未完成平衡。

本轮新增的 20 棋子动作、预警、弹道、粒子、状态和特殊死亡表现，只完成代码、构建与 Node 规则验证，尚未进行浏览器画面验收。
