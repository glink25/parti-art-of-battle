- `pnpm check` 通过：TypeScript strict、模块边界和内容表校验有效；内容为 62 棋子、24 羁绊、10 装备。
- 43 项纯逻辑测试通过；新增覆盖完整名单、声明式效果、纠正后的标签、自爆归属、不朽延战、行为羁绊、斩杀、减甲、魅惑、装备失效、建筑限制、异虫二合一和炼金塔奖励。
- `pnpm build` 通过，Parti filesystem 包契约有效；封面包大小 158023 字节。
