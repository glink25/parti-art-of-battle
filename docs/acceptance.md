# 人工验收清单

以下项目尚需真实设备操作。构建、Node 模拟或 HTTP 能返回页面都不等于这些项目已通过。

## 桌面本地开发预览

- `pnpm dev`，打开开发地址。A 席开始，购买一枚棋子，点击部署到己方半场；敌方半场应拒绝。
- 切换 B 席进行相同操作；A 与 B 共用棋盘但金币、商店、备战区独立。
- 测试点击、长按和拖拽。拖动时商店收起，跟手模型、原位轮廓、合法/非法落点可见；放回原位取消，非法格不提交。松手后商店恢复原显隐状态。
- 拖出画布、窗口失焦、右键、Escape、触摸取消、旋转屏幕和切换战场后，不应残留拖动状态。
- 将棋子放到公共区，从另一席领取。两席操作相同目标时，只接受第一个有效版本。
- 拖动自己的棋子时，出售区应位于整排备战区下方的底部操作栏内，不覆盖或紧邻公共格；松手后取消不出售，确认只出售一次。队友和公共区棋子不出现有效出售区，详情面板出售仍直接提交。装备支持拖到棋子，也支持先点装备再点目标；槽位已满时明确提示原因。
- 拖到占格完成合法换位；点击另一棋子只切换选择，显式「换位」后再点击才交换。满人口时自己的场上/备战交换仍有效，队友私有区与公共区交换失败。
- D 刷新、F 买经验、Space 商店、Escape 取消；长按只显示详情，不意外移动或出售。
- 凑三合一，包括私人区满但购买可立即合成、同一拥有者的公共棋子参与后结果留在公共区、不同拥有者不跨玩家合成，以及合成后装备溢出回包。
- 点击不同机器人队伍观战，查看攻击朝向、命中闪光、伤害数字、阶段和胜负横幅；通过返回本队按钮回到自己的棋盘。
- 按内容清单抽查全部 62 枚棋子的普攻与技能表现 ID，并逐类确认起手、释放、弹道或近战冲击、范围预警、命中和后摇；范围单位离开预警区后不受该次范围技能伤害。
- 检查眩晕、中毒、沉默、魅惑/转火、减甲、斩杀、装备失效、形态切换、极限模式、召唤、穿山甲开场突进、爆裂虫延时自爆和不朽者延迟死亡；切换战场或回放跳转后不得残留上一场特效。
- 战斗阶段左侧伤害榜只统计当前观战阵营；切换同一场战斗的另一方、切换其他战场或恢复回放后应立即清零并重建，治疗和护盾不计入伤害。
- AI 决策与本地双席切换只在左上设置 → 开发工具中出现，正常战场不显示日志、协议说明或表单区。

## Parti 双设备

- 构建并导入 `artifacts/parti.room.zip`。房主邀请一个设备，双方都能看到相同准备状态。
- 房主是第一席，不额外创建第三名游戏玩家。第三个连接由房间容量拒绝。
- 只有房主可开始；双人准备完成提前战斗。机器人完成剩余有界操作后冻结。
- 商店与操作结果以快照为准；多次快速点击不会重复扣款或购买另一个版本的货架。失败提示出现在最近操作附近；请求等待中相关对象不重复提交。
- A 拖动时 B 移动/换位/转交同一棋子，或 A 买棋合成拖动中的源：手势取消且提示更新。无关金币/商店快照不打断仍合法的拖拽。
- A 拖入出售区等待确认时，由其他有效操作令该棋子移动、转交或合成后，确认弹层应关闭且不得误售其他棋子。
- 双方争抢公共棋子、同时交换相同两枚场上棋子，只接受第一个有效版本；不得发生一半换位。
- 模拟连接暂时中断：等待操作以同一 commandId 重发，恢复后以实际回执解锁；准备已结束时的重复成功请求仍返回原结果。
- 两个设备观看相同战斗，结果哈希一致；画面可以有网络延迟，但最终胜负必须一致。
- 在设备时钟有偏差时验证倒计时采样；任何客户端显示误差不能延长权威操作期限。
- 完整打完一局，验证淘汰返池、排名和最后结算。

## 恢复

- 准备阶段刷新房主：金币、货架、棋子保留，重新有 25 秒，不重复发收入和经验。
- 计算中刷新房主：未完成战斗从冻结输入重新计算；已有结果不重复提交。
- 播放中刷新房主：重新安排回放，最终只扣血一次。
- 结算展示期间刷新房主：只进入下一轮，不重复扣血或发工资。
- 非房主短暂断线：不暂停，原阵容继续；平台恢复原身份后可继续操作。
- 非房主战斗中重连：从当前快照取得战斗输入，并定位到当前播放时间。
- 两席进入后，在等待大厅让一人正式离开，再用新身份进入；开局后则不转移老席位给新身份。

## 手机

记录设备型号、系统、浏览器版本、房间包版本。至少验证 iOS Safari 和 Android Chrome 各一台。

- 至少检查桌面 1440×900、手机横屏 844×390、竖屏 390×844，以及 320 CSS px 窄屏。页面无整体滚动，棋盘与双方备战格完整可见，Parti 胶囊、系统安全区及关键 HUD 不遮住落点。
- 通过实体棋盘点选、点空格部署；长按查看详情；从备战区连续完成部署、换位、公共交付、装备与出售。不依赖 hover 或二维按钮面板。
- 排名和羁绊通过边缘按钮展开；列表自身可滚动。主要控件触控面积至少 44 CSS px，HP、费用、等级和倒计时可读。
- 连续切换商店展开/收起、开始拖拽、释放、进入战斗，棋盘取景稳定且不让商店遮住目标格。
- 在 844×390 检查中央五卡横幅、顶部等级概率、左右侧栏和底部主操作；战斗开始后商店自动收起且入口禁用，排名和伤害长列表可在栏内滚动。
- 切换浏览器标签或锁屏后回来能恢复显示；后台暂停期间不凭客户端倒计时修改胜负。
- 连续多个回合观察帧率与内存。目标手机 ≥30 FPS，桌面 ≥60 FPS；当前尚无实测认证。
