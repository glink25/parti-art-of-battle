# 棋子辨识度优化批次

目标：允许风格化和适度低面数，但必须有完整结构、明确身份特征和不同剪影。禁止以几个基础形状、同一模型换色或部件数量作为完成依据。

费用层级：高费棋子允许更大体型与更突出的标志性结构，优先通过翼展、体长、背鳍、冠饰等体现；低费保留完整结构并控制体量。以内容中的实际费用为准，不改费用或战斗占格。此前批次高费棋子的统一体量复查仍待后续进行。

每批流程：原始渲染 → 独立造型重做 → 同比例彩图与 80px 剪影 → 侧后视图 → 普攻/技能关键帧 → 修正 → check/test/build。桌面截图不代表真机玩法或性能验收。
